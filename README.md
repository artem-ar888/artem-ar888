## Мои проекты:

### ⚡ [Автоматизация мобильного приложения «Мобильный хоспис»](https://github.com/artem-ar888/fqamid-diplom.git)

Провёл полный цикл тестирования нативного Android-приложения (*Espresso*) как часть дипломной работы. Составил **тест-план**, **чек‑лист**, написал **64 тест-кейса** для ручного тестирования, выявил и завёл **21 баг-репорт** в GitHub Issues. Автоматизировал **85 сценариев** с использованием *Idling Resources*, что обеспечило стабильность тестов без *sleep*. Применил *Computer Vision* для анализа графических элементов. Время полного регресса сократилось более чем в **20 раз**. На основе результатов дал рекомендации по улучшению UI/UX под гайдлайны *Material Design 3*.

**Технологии:** Mobile Testing, Java/Kotlin, Espresso, Page Object Model, Allure Report.

### 🛠 [Командная разработка банковского приложения на Java](https://github.com/artem-ar888/javaqa-team-diplom-2.git)

В рамках курса «Java для тестировщиков» совместно с напарником реализовали функционал банковских счетов: пополнение, покупка, прогноз процентов по кредиту/сберкнижке. Нашли и исправили **21 баг**, используя принцип *cross-check* — каждый искал дефекты в коде другого. Закрепил навыки работы с GitHub (*ветки*, *Pull Request*) и написания юнит-тестов *(JUnit)*.  

**Технологии:** Java, JUnit, GitHub Collaboration.

### 📋 [Ручное тестирование интернет-магазина Henderson.ru](https://docs.google.com/spreadsheets/d/1S7Ne3fWuEzs7QcshVNFh41tenLYpPbuN7PMe3I4oCTI/edit?usp=sharing)

Провёл комплексное исследование реального коммерческого сайта без доступа к исходному коду. Выполнил следующие задачи:

- Составил **многоуровневый чек‑лист из 96 проверок**, охватывающий все модули личного кабинета: от навигации до работы с отзывами (расставил им приоритеты).
- Написал **18 атомарных тест‑кейсов** по восстановлению пароля (по Email и телефону) с использованием техник *границы* и *негативного тестирования*.
- Нашёл и оформил **7 багов** в Google Sheets с указанием критичности *(от Minor до Major)*, окружения, шагов воспроизведения и скриншотов.
- Провёл исследовательское тестирование страницы карточки товара: изменял цену продукта через консоль разработчика (**DevTools**) на экстремальные значения — **1₽ и 10 000 000₽**, чтобы проверить верстку.
- Изучил сетевой трафик (**Network tab**) при загрузке главной страницы, чтобы найти структуру запроса получения списка стран для менеджера проекта.
- Проанализировал техническое задание по восстановлению пароля и выявил риски безопасности (сброс старого пароля).

**Результат:** закрепил навыки полного цикла ручного тестирования: от анализа требований и составления документации до поиска дефектов и исследования UI без помощи разработчиков.

**Технологии:** Java, Selenide, Page Object, MySQL, Docker Compose, GitHub Actions.

### 📽 [Кросс-браузерное тестирование онлайн-кинотеатра](https://github.com/artem-ar888/jsaqa-hw7-cypress-cinema.git)

Покрыл основные пользовательские сценарии (поиск фильмов, покупка билетов) автоматизированными тестами на Cypress. Реализовал проверку целостности данных после выполнения сценариев через работу с элементами DOM. Настроил параллельный запуск тестов для ускорения прогонов.

**Технологии:** JavaScript, Cypress, Parallel Testing, Custom Commands.

### 🔥 [Нагрузочное тестирование веб‑сайта кинотеатра](https://github.com/artem-ar888/loadqa03.git)

Провёл два раунда тестирования: добавление комментария через расширение BlazeMeter Chrome и покупка билетов через полный пользовательский путь в JMeter. Смоделировал поведение реального пользователя через паузы (*Constant Timer*) и динамическую генерацию данных. Собрал ключевые метрики производительности: задержку (**Latency**), процентили времени отклика (**p90, p95**) и пропускную способность (**Throughput**). Поднял локальное окружение сайта на базе *Docker Compose*.

**Технологии:** Load Testing, Performance Analysis, Apache JMeter, BlazeMeter, Docker Compose.
